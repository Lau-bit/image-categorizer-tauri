Settings

Text Analysis Thresholds

Images at or under both thresholds are classified "Low Text"; anything above either threshold is "High Text". Use "Analyze New" with Text checked to apply OCR.

Explicit Analysis Threshold

Images whose max explicit-content confidence score meets or exceeds this value are classified "Explicit"; all others become "Safe". Lower = more sensitive. Re-classify without re-running by moving the slider — no inference needed. 


        


        

          Vision Descriptions (Images → Words)
          

            Describes images in words with a local OpenAI-compatible vision model. Load a vision
            model in LM Studio and start its local server, then tick "Describe" under Analyze.
            Each description is saved beside the library (a .image-categorizer-descriptions
            folder, one file per image, plus an index.json) so other apps — e.g. Local
            LLM Chat — can read an image as text. Explicit images are skipped, so run Explicit first.
          

          
          
          

            

            
          

          

          
          

            LM Studio keeps only one model in memory for the whole machine, so a model left loaded
            after a run costs every other app on the box. When this app is the one that
            loaded it, it asks LM Studio to unload it after a quiet spell — quiet meaning no
            requests from any app and no activity in this window. Another app using the
            model keeps it loaded, and a model somebody else loaded is never touched. Applies from
            the next load: LM Studio fixes the timeout when the model comes up.
          

          
          


          Video Chunk Plan
          

            "Video Dedup" reads each screenshot's title bar, groups frames from the same video, and
            samples 10 per video for description — so 500 near-identical frames don't each get
            described. The plan is a standalone file you can inspect, hand-edit, or discard.

          Window Position & Size
          

            Move and resize the window the way you want it, then save it as the default — every
            launch reopens exactly there. Nothing is saved automatically, so shoving the window
            around later never overwrites what you chose. Saving while maximized reopens maximized.
          

          

          

            
            
          

        


        

          Automatic Daily Refresh
          

            Runs a rescan (and, if selected, analysis) once a day via Windows Task Scheduler, even
            if the app isn't open — so the library is already up to date next time you open it.
            While it runs, a tray icon appears; right-click it and choose "Cancel refresh" to stop
            immediately, e.g. before a demanding game.
